# 💰 Finance Manager Pro

A comprehensive personal finance management web application for tracking budgets, expenses, debts, taxes, and financial goals.

## Features

### 📊 Dashboard Overview
- Real-time financial summary
- Total income, expenses, debt, and net balance
- Tax liability estimates
- Savings rate calculation
- Interactive charts (income vs expenses, expense breakdown)

### 💵 Income Management
- Track multiple income sources
- Support for different frequencies (monthly, yearly, weekly, one-time)
- Income history and analytics

### 💳 Expense Tracking
- Categorize expenses (Food, Transport, Utilities, etc.)
- Add descriptions for detailed tracking
- View expense history and trends
- Date-based filtering

### 📈 Budget Planning
- Set monthly spending limits by category
- Real-time budget status with visual progress bars
- Overspending alerts
- Compare actual spending vs. planned budget

### 💰 Debt Management
- Track multiple debts (loans, credit cards, mortgages)
- Interest rate and payment information
- Automatic payoff date calculation
- Interest cost projection

### 🧮 Tax Calculator
- Calculate federal, state, and local taxes
- Social Security and Medicare calculations
- Support for multiple filing statuses
- Deduction management
- Effective tax rate calculation
- Take-home pay estimation

### 🎯 Financial Goals
- Set and track financial goals
- Visual progress tracking
- Days remaining countdown
- Target amount and savings progress

## Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Charts**: Chart.js 3.9.1
- **Storage**: LocalStorage (Browser-based persistence)
- **Responsive**: Mobile-friendly design

## Getting Started

### Installation

1. Clone the repository:
```bash
git clone https://github.com/kevorwilliams18-a11y/finance-manager.git
cd finance-manager
```

2. Open in your browser:
   - Simply open `index.html` in your web browser
   - No server or installation required!

### Usage

1. **Add Income** → Track all your income sources
2. **Record Expenses** → Log daily expenses by category
3. **Set Budgets** → Define spending limits
4. **Track Debts** → Monitor loans and credit cards
5. **Calculate Taxes** → Estimate tax obligations
6. **Set Goals** → Plan your financial future

## Data Storage

All data is stored locally in your browser using LocalStorage. Your financial information:
- Never leaves your computer
- Persists across browser sessions
- Can be backed up by exporting from browser storage
- Is automatically saved after each change

## Tips for Best Results

1. **Regular Updates**: Update expenses and income regularly for accurate tracking
2. **Category Consistency**: Use consistent category names for better analysis
3. **Realistic Budgets**: Set achievable budget limits
4. **Tax Planning**: Use the tax calculator quarterly for better planning
5. **Goal Setting**: Set SMART (Specific, Measurable, Achievable, Relevant, Time-bound) goals

## Limitations & Notes

- Data is stored in browser's LocalStorage (not synced across devices)
- Tax calculations are estimates (consult a tax professional for accurate filing)
- To clear all data: Open browser DevTools → Storage → LocalStorage → Delete All
